点击 Webhook

每租户一个端点。路径不是 /api/webhooks 根：

  • PUT /api/webhooks/endpoint — JSON 字段 url（必填）、enabled（可选布尔）、deliveryMode/aggregateWindowSeconds/aggregateMaxEvents（可选，缺省保持原值）。新建时响应带一次明文 secret；更新 url 不轮换 secret。
  • GET /api/webhooks/endpoint — 查看当前配置，secret 只有掩码 secretMasked。
  • POST /api/webhooks/endpoint/rotate-secret — 轮换，明文只此一次。
  • DELETE /api/webhooks/endpoint — 删除。

未配置环境变量 LINKFORGE_WEBHOOK_SECRET_KEY（32 字节 AES 主密钥的 Base64）时，PUT 与轮换返回 503。

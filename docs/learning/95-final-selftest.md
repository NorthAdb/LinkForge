## B 卷：场景分析（5 题，达标线 4）

从 [94-scenario-drills.md](94-scenario-drills.md) 的 20 题中**随机抽**（每次做换一批），遮住排查步骤口述四拍路径：确认现象→缩小范围→验证假设→修复防复发。评分看第一拍是否就找对了「先确认什么」。

## C 卷：手撕代码（3 题，达标线全部 20 分钟内完成）

从 [92-interview-coding.md](92-interview-coding.md) 的 20 张卡随机抽 3 张。要求：先复述题意与约束、说暴力解再优化、写完主动走一个例子、报复杂度带来源。缺一步扣半题。

## D 卷：项目讲述（10 问，达标线 9）

从 [91-interview-project.md](91-interview-project.md) 的追问树抽，必含这四问：

1. 讲一遍跳转的完整链路（对照 [81](81-linkforge-flows.md) 的十二站判定门）。
2. 为什么命中缓存还要读 DB？
3. 消息不丢是怎么保证的（讲到 Outbox 与幂等）。
4. 讲一个你亲自处理的故障（对照 [82](82-linkforge-decisions.md) 的 F1 时区案例，如实说是学习项目中的复现）。

其余六问从追问树随机。评分：被追问第三层还能答才算过。

## E 卷：简历与表达终检（全部通过）
